# クイズ管理: 問題の一覧・追加・編集・削除機能を追加する

## 概要

クイズ問題を管理画面から一覧表示・追加・編集・削除できるようにする。
現在の4択形式、採点、正解・解説の表示に対応する。

## 背景・目的

現在は `main.py` の `QUESTIONS` に問題を直接定義しており、内容の変更にコードの編集が必要になる。
管理画面から問題を更新できるようにし、クイズの運用を容易にする。

## 下書きの前提・確認事項

- 「最大5問」は、今回の案では登録可能な問題数も最大5問として扱う。
  問題を6問以上蓄積して1回に最大5問出題する運用を想定する場合は、この上限を変更する。
- 管理者認証の要否と利用範囲（ローカル利用／外部公開）は実装前に決定する。
  外部公開する場合は、管理画面と管理APIへのアクセスを管理者に限定する。

## 要件

- 管理画面から登録済み問題を一覧表示できる。
- 問題文、4つの選択肢、正解の選択肢1つ、解説を登録・編集できる。
- 問題文、各選択肢、解説の未入力・空白のみの入力を拒否する。
- 選択肢数と正解指定の妥当性をサーバー側でも検証する。
- 登録可能な問題数は最大5問とし、上限を超える追加をサーバー側で拒否する。
- 削除前に対象の問題を確認でき、キャンセルできる。
- 問題に安定した識別子を付与し、編集や他の問題の削除で変化させない。
- 変更内容を保存し、サーバー再起動後も保持する。保存方式は実装時に選定する。
- 新しく開始したクイズに管理画面での変更を反映する。
- 登録問題数が5問未満の場合は、その件数まで出題数を選択できる。
- 問題が0件の場合はクイズを開始できず、問題未登録の案内を表示する。
- 回答中の問題が編集・削除された場合の扱いを定義し、回答時と異なる内容で採点しない。
- 一般利用者向けの出題APIには正解と解説を含めず、採点後に表示する。

## 受け入れ条件

- [ ] 管理画面から一覧表示・追加・編集・削除を完結できる。
- [ ] 登録した問題をクイズで回答でき、指定した正解と解説で採点結果が表示される。
- [ ] 必須項目の不足、不正な選択肢数・正解指定を画面とAPIで拒否できる。
- [ ] 5問登録済みの場合、6問目を追加できない。
- [ ] 削除のキャンセルで問題が保持され、確定で削除される。
- [ ] サーバー再起動後も追加・編集・削除の結果が保持される。
- [ ] 出題可能な問題数に合わせて開始画面が動作し、0件の場合にも適切に案内される。
- [ ] 回答中に問題が更新されても誤った採点が行われない。
- [ ] 出題APIから正解・解説が漏れない。
- [ ] 既存のクイズ回答・採点・再挑戦が引き続き動作する。
- [ ] 決定した管理者アクセス方針が画面とAPIの双方に適用される。

## テストシナリオ

1. **追加と出題**：登録数が4問以下の状態で有効な問題を追加し、新規クイズに反映されることと、正解・不正解の採点を確認する。
2. **入力検証**：未入力、空白のみ、選択肢の過不足、範囲外の正解指定を送信し、登録・更新が拒否され、既存データが保持されることを確認する。
3. **登録上限**：5問登録した状態で管理画面・APIから追加を試み、6問目が保存されないことを確認する。
4. **編集**：問題文・選択肢・正解・解説を変更し、識別子を維持して新しいクイズと採点結果に反映されることを確認する。
5. **削除**：削除をキャンセルした場合は保持され、確定した場合は新規クイズに出題されないことを確認する。
6. **永続化**：追加・編集・削除後にサーバーを再起動し、変更結果が保持されることを確認する。
7. **登録数の変化**：1〜4問および0問の状態で、出題数選択と未登録の案内を確認する。
8. **回答中の更新**：クイズ開始後に対象問題を編集・削除し、決定した扱いに従って採点または再開始の案内が行われることを確認する。
9. **公開APIと回帰**：出題レスポンスに正解・解説が含まれないこと、既存の採点・再挑戦が動作することを確認する。
10. **管理者アクセス**：外部公開する場合、権限のない利用者が管理画面と管理APIで問題を参照・変更できないことを確認する。

## 対象外（本案）

- カテゴリー・難易度・画像付き問題への対応
- 問題の一括インポート・エクスポート
- 回答履歴・ランキング機能
